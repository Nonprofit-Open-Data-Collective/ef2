# Plot Table Structure

Plots the hierarchical structure of a table using data.tree
visualization.

## Usage

``` r
plot_table_str(table.name)
```

## Arguments

- table.name:

  A character string specifying the table name.

## Value

None. Displays a plot of the table structure.

## Examples

``` r
plot_table_str("F9-P03-T01-PROGRAMS-OTHER")
#> Error in plot.Node(nd): Package "DiagrammeR" is required to plot a `data.tree::Node`object. Please install it.
```
