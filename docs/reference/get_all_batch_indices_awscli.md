# Get All Batch Index Filenames Using CLI

Retrieves the filename of the most recent AWS index.

## Usage

``` r
get_all_batch_indices_awscli()
```

## Value

A character string representing the filename of the most recent index.

## Examples

``` r
if (FALSE) { # \dontrun{
get_all_batch_indices_awscli()
} # }
```
