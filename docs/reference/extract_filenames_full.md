# Extract Index Filenames

Extracts filenames matching a specific pattern from a vector of strings.

## Usage

``` r
extract_filenames_full(strings)
```

## Arguments

- strings:

  A character vector containing strings to search.

## Value

A character vector of matched filenames.

## Examples

``` r
if (FALSE) { # \dontrun{
index.list <- get_index_list_awscli()
extract_filenames_full( index.list )
} # }
```
