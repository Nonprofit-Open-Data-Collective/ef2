# ef2: Tools for Building and Maintaining the IRS 990 Efiler Database

Provides tools for retrieving, parsing, and flattening IRS 990 e-file
XML data into relational form, including schema alignment, batch
processing, and DuckDB integration. Supports large-scale ingestion and
alignment of IRS e-file data using concordance crosswalks and
parallelized retrieval.
